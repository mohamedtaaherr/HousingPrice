#  House Price Prediction - Complete ML Pipeline

##  Project Overview
End-to-end machine learning project for house price prediction including:
- **Unsupervised Learning** (K-Means Clustering)
- **Supervised Learning** (Classification & Regression)
- **Comprehensive EDA** (Univariate, Bivariate, Multivariate)
- **Multiple Regression Models** (Linear, Ridge, Lasso, Random Forest)

##  Technologies Used

| Category | Libraries |
|----------|-----------|
| Data Processing | Pandas, NumPy |
| Visualization | Matplotlib, Seaborn |
| Machine Learning | Scikit-learn |
| Statistics | SciPy, Statsmodels |

##  What This Pipeline Does

| Step | Description |
|------|-------------|
| **1. Data Preparation** | Load, clean, encode categorical variables |
| **2. EDA** | Distributions, correlations, boxplots, 3D scatter |
| **3. Outlier Detection** | IQR method for anomaly detection |
| **4. Multicollinearity** | VIF (Variance Inflation Factor) analysis |
| **5. PCA** | Dimensionality reduction & visualization |
| **6. Clustering** | K-Means with Silhouette & Davies-Bouldin scores |
| **7. Classification** | Random Forest (High/Low price prediction) |
| **8. Regression** | 4 models with MAE, RMSE, R² comparison |
| **9. Residual Analysis** | Model diagnostics and validation |
